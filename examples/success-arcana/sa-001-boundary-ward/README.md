# SUCCESS-ARCANA-001 — 七曜反転聖域

`BoundaryReflectionController`を登録・ACTIVATEし、Region境界を横切るunauthorized targetへbounded normal impulseを適用するexperimental fixture。

- required classではなく`Experimental-Arcana-0`。
- target selectionはRegion/crossing predicateから導出するが、authorityはper-actuation Capability/Lease revalidationでのみ成立する。
- admitted fixture: mass 10 kg、incident normal momentum 20 kg·m/s、restitution 0.8、impulse 36 kg·m/s、dissipation 7.2 J。
- target/anchor Momentum、Energy ledger、reflection Eventを一つのatomic actuation groupとしてaccountする。
- authorized crossingはmomentumを変更しない。domain/timing/resource逸脱はoverload/failureへfail closedする。
