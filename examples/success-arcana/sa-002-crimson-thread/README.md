# SUCCESS-ARCANA-002 — 紅糸代償法

小規模な可逆的負傷を`TreatmentDecomposition`へ分解し、Stabilize / Repair / Manifestを順にcommitするexperimental fixture。

髪・赤糸は`CorrespondenceToken` evidenceでありpatient identityではない。TRANSFER可能なのはEnergy/Matter等だけで、裂傷形状は`DamageDescriptor`に基づくRECONFIGUREである。Repairは`IdentityPolicy<Organism>`、medical Capability/Lease、donor matter、sink capacityを要求する。proxy破壊からpatientへのreverse effectは存在しない。

fixture-specific SandboxProfileは800 Jを許可し、620 Jという値はsynthetic profile evidenceであって普遍定数ではない。
