# 魔術言語仕様 v0.3

v0.2を基礎に、制御構造・関数・抽象化を追加する。

## 1. Pure / Effectful separation

純粋計算と世界作用を分離する。

`fn` は世界状態へアクセスしない純粋関数。

`proc` はeffectfulな内部手続き。

`spell` は外部から発動可能なeffectful entry point。

## 2. 不変束縛とSSA

MIRの `let` は再代入不可。

高級言語の可変変数はMIRへ落とす際にSSA風の別束縛へ展開できる。

## 3. Measurement

観測結果は現在値へのlive referenceではない。

```text
Measurement<Q> {
    value
    uncertainty
    observed_at
    revision
}
```

古い観測には `StaleObservation` の可能性がある。

## 4. Truth

観測誤差を考慮し、比較は必要に応じて三値を返す。

```text
Truth = True | False | Indeterminate
```

`Indeterminate` を無視した暗黙Bool変換は避ける。

## 5. 条件分岐

```text
if condition { ... } else { ... }

match measurement_condition {
    True => { ... }
    False => { ... }
    Indeterminate => { ... }
}
```

分岐全体のeffectは各枝のeffectの和集合。

## 6. 関数

```text
fn kinetic_energy(
    mass : Quantity<Mass>,
    velocity : Quantity<Velocity>
) -> Quantity<Energy> {
    return 0.5 * mass * velocity^2;
}
```

`fn` 内で世界へアクセスする命令は原則禁止。

## 7. Proc

```text
proc push(
    source : Ref<Anchor>,
    target : Ref<Object>,
    p : Quantity<Momentum>
)
! {
    Channel<Momentum>,
    Transfer<Momentum>
}
{
    let ch = channel<Momentum>(source -> target);
    transfer ch, p;
}
```

宣言effectは本体から推論されたeffectを包含する必要がある。

## 8. Generics

```text
proc relay<Q : Conserved>(
    ch : Channel<Q>,
    q : Quantity<Q>
)
! { Transfer<Q> }
{
    transfer ch, q;
}
```

`Temperature` のような非保存量を `Conserved` としてTRANSFERしてはならない。

## 9. 反復

有限回数の `for/repeat` を基本とする。

```text
repeat 10 { ... }
```

世界作用を含む上限なし `while true` は禁止。

必要なら:

```text
while condition limit 100 { ... }
```

など静的上限を要求する。

`CONSTRAIN` は継続制御であり、ユーザーコードの `while` で代替しない。

## 10. Termination

純粋再帰は終了性を証明できる場合に許可可能。effectfulな無制限再帰は原則禁止し、証明不能なら `TerminationProofFailure`。
