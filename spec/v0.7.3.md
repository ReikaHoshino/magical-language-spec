# 魔術言語仕様 v0.7.3

v0.7.2のLanguageAdapter / NSR / cross-language conversion contractを基礎に、
NSRのexecution-relevant semantic equalityを決定論的に比較する
`CanonicalSemanticProjectionV1` / `SemanticFingerprintV1` を正式化する。

## 1. 中心原則

```text
SemanticFingerprint != artifact content_hash
Canonical semantic projection != full NSR serialization
Semantic equality != byte-for-byte source equality
Role order != source word order
Unknown != omitted
Unknown != null
null != omitted
Provenance difference alone != semantic drift
Evidence difference alone != semantic drift
Semantic change => fingerprint change (for represented V1 semantics)
```

## 2. CanonicalSemanticProjectionV1

```text
CanonicalSemanticProjectionV1(NSR)
```

top-level include:

```text
kind
action       // presentならexplicit nullを保持
roles
modifiers
conditions
constraints
```

top-level exclude:

```text
schema_version
provenance
ambiguity
semantic_fingerprint
unknowns
```

`unknowns` はdiagnostic/index summaryであり、semantic Unknown occurrenceはsemantic
value位置に置く。

current semantic value fields:

```text
kind
semantic_kind
mode
selector
value
unit
reason
```

`evidence_ids` とlanguage-specific source/provider metadataは除外する。
`selector` / semantic `value` payloadはsemantic contentとして含める。

V1がsemantic/provenance classificationを決められないschema-valid extensionは
黙って無視せずdiagnosticとする。

## 3. Omitted / explicit null / Unknown

```text
field omitted
!=
field present with JSON null
!=
{"kind":"Unknown","reason":"..."}
```

canonicalizationはこの3状態を相互変換しない。

## 4. Ordering

- object property orderはRFC 8785 JCSでcanonicalizeする。
- rolesはorder-independent multisetとしてprojected role/valueでsortし、duplicatesを保持する。
- modifiers/conditions/constraintsはV1ではarray orderを保持する。
- undocumented aliasing、case folding、whitespace trimming、Unicode normalizationを行わない。

## 5. SemanticFingerprintV1

```text
SemanticFingerprintV1(NSR)
  = SHA-256(
      UTF-8(
        JCS(CanonicalSemanticProjectionV1(NSR))
      )
    )
```

machine-readable representation:

```text
sf:v1:sha256:<64 lowercase hexadecimal digits>
```

JCS/I-JSONで意味を変えず表現できないnumeric/extension valueはcoerceせずdiagnosticとする。

## 6. Artifact hash separation

JCS + SHA-256は`SemanticFingerprintV1`だけのdecisionである。generic artifact
`content_hash`, `registry_hash`, その他domain hashのcanonical byte encoding/hash
algorithmは未決定のままであり、本releaseはこれを決定しない。

## 7. Assumptions

execution-relevant assumptionはconditions/constraints/semantic values等のstructured
NSR contentとして存在する場合のみfingerprintへ含める。FeasibilityReport内のfree text、
comment、evidence、provider metadataをfingerprintへ注入しない。

## 8. Canonical fixture

```text
Patient  = SemanticKind(Energy, mode=Thermal)
Source   = SelectorProposal(Symbolic("water"))
Goal     = SelectorProposal(Symbolic("air"))
Quantity = Unknown(MissingSurfaceArgument)
```

expected fingerprint:

```text
sf:v1:sha256:ee37e2e102ed939afd04b6142faa5c63c0cb49b0dc86987b2ffa5656c259df48
```

adapter provenance、ambiguity metadata、evidence IDs、object key order、role orderだけが
異なるNSRは同じfingerprintを得る。semantic value、quantity/unit/value、Unknown reason、
omitted/null/Unknown差は異なるfingerprintを得る。

## 9. Round-trip scope

rendererはv0.7.3時点で未実装である。実装済みfixtureは異なるadapterから生成されたと
みなす2 NSRのNSR-layer equivalenceを検証する。real
source→renderer→source round-tripはrenderer実装までTODOとする。

## 11. Compatibility

v0.7.3はNSR semantic equalityの意味をversioned profileとして新規固定するsemantic
specification changeである。future profileは新しいprefix/versionで共存し、V1 equality
semanticsをsilentに変更しない。

MIR grammarとMKI primitivesは変更しない。
