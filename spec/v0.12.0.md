surfaceをversioned stable case ID、reverse rule coverage、machine-readable requirement matrixとして

Guarantee rehearsalがPASSし、Issue #40が全5 gateをcertifyするまでIssue #38を解放しない。

## 2. Complete required-surface matrix

`conformance/v1-required-surface.json`はIssue #38のminimum conformance promiseを14 claimとして
列挙する。各claimはowning classとstable required case IDを持つ。

```text
V1-CONF-001 .. V1-CONF-014
```

matrix caseは:

- `conformance/manifest.json`にrequired caseとして存在する;
- owning classの`required_case_ids`に含まれる;
- exact current normative headingとtest/fixture locatorを持つ;
- `conformance/rule-coverage.json`からreverse coverageされる;

ことをregressionで強制する。

Adapter-lat-1.0はcommon source normalization、StrictReject、ContextualDeterministic、
LegacyPermissive ambiguity traceをrequired evidenceとして持つ。automatic language detectionやfull
historical/register Latin breadthは引き続きnon-goalである。

minimum Energyを使用するselection ruleをrequired evidenceへ含める。

```text

permissive selection != safety bypass
evaluation != authoritative world mutation
```

## 5. Promoted runtime evidence

Runtime-1.0は:

- supported canonical executionがexact six MKI operationsをexerciseすること;
- sandbox Energy ceiling超過をmutation前にfail closedすること;
- late unrelated entityがPrepareBound terminalを暗黙retargetしないこと;

既存PREPARE/COMMIT、Capability/Lease/conservation、scheduler/time、replay、World Kernel、emergency
stop evidenceは維持する。

## 6. Preserved compatibility guarantee

v0.11で確定したseven-domain compatibility coverage、v1.x stable scope、deprecation、exact migration
contractを変更しない。

```text
shared metadata rules != shared compatibility algorithm
hash mismatch alone != incompatibility
release version != compatibility oracle
migration success != authority, trust, or admission
```

## 7. Explicit non-requirements

次はIssue #35 policyどおり、別途promotionされない限りv1.0 blockerではない。

- non-reference language adapter breadth;
- automatic language detection / GUI;
- production WorldIndex storage and distributed runtime;
- high-performance parallel scheduler;
- public serialized ECIR;
- exhaustive physical/chemical/biological models;
- full theorem proving;
- historical/register profiles beyond required fixtures。

isolated wheel、isolated sdistから実行する。fixture expected truthはSpecification/conformance ownedで
あり、reference implementation outputから盲目的に生成しない。

```text

v0.12 conformance success != Issue #38 READY
Gate 4 PASS -> Issue #72 final Gate 5 rehearsal
```

historical `spec/v0.11.0.md`以前は変更しない。
