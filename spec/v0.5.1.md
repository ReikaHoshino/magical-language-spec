# 魔術言語仕様 v0.5.1

v0.5を基礎とする整合性・参照資料の保守リリース。

本版はMKIの意味論を変更せず、SI次元基底、MIR文法、用語、ラテン語資料の整合性を明文化する。

## 1. SI次元基底

MIRの次元ベクトルはSIの7基本単位に正規化する。

```text
(kg, m, s, A, K, mol, cd)
```

代表例:

```text
Mass              = (1,0,0,0,0,0,0) = kg
Length            = (0,1,0,0,0,0,0) = m
Time              = (0,0,1,0,0,0,0) = s
ElectricCurrent   = (0,0,0,1,0,0,0) = A
Temperature       = (0,0,0,0,1,0,0) = K
AmountOfSubstance = (0,0,0,0,0,1,0) = mol
LuminousIntensity = (0,0,0,0,0,0,1) = cd
Velocity          = (0,1,-1,0,0,0,0) = m s^-1
Momentum          = (1,1,-1,0,0,0,0) = kg m s^-1
Energy            = (1,2,-2,0,0,0,0) = kg m^2 s^-2
Power             = (1,2,-3,0,0,0,0) = kg m^2 s^-3
Charge            = (0,0,1,1,0,0,0) = A s
```

`cd` を次元基底に含めることは、`LuminousIntensity` を保存量・TRANSFER可能量とすることを意味しない。TRANSFER可能性は意味型側の制約（例: `Conserved` / `Transferable`）で判定する。

v0.1〜v0.5の文書に残る6成分表記は歴史的スナップショットとして保持し、v0.5.1以降の現行仕様では7成分を正規形とする。

## 2. Async TRANSFERの構文整合

v0.5で `TRANSFER` は非同期実行され、`TransferHandle<Q>` を返しうる。

従ってMIRではTRANSFERを式としても扱う。

```text
let tx : TransferHandle<Energy> =
    transfer ch, q;

await tx;
```

返値を使用しない場合のみ、式文として次も許容する。

```text
transfer ch, q;
```

## 3. MIR文法の補完

v0.3〜v0.5本文に存在していたが暫定EBNFに欠けていた以下を文法へ追加する。

```text
for
match
await all
synchronize ... within ...
prepare { ... }
acquire-expression
transfer-expression
```

`CONSTRAIN` は継続制御、`while` はユーザーコード上の有限反復であり、両者の区別は維持する。

## 4. Measurementの次元

`Measurement<Q>` は意味型 `Q` に対応する次元 `Δ(Q)` を持つ測定値である。

完全表記を必要とする場合:

```text
Measurement<Q, Δ(Q)>
```

通常のMIR表記では `Measurement<Q>` を略記として用いてよい。

## 5. Channelの型制約

`Channel<Q>` の `Q` は単に次元を持つ量ではなく、そのChannel実装が輸送可能な意味型でなければならない。

概念的には:

```text
Channel<Q : Transferable>
```

保存量を扱う一般的TRANSFERでは、さらに `Q : Conserved` を要求する。

従って `Channel<Energy>` / `Channel<Momentum>` / `Channel<Charge>` は成立しうるが、`Channel<Temperature>` や `Channel<LuminousIntensity>` はそのままでは成立しない。

## 6. 熱の扱い

`Heat` / `Calor` を独立した保存量型とはしない。

```text
Transfer<Energy, mode=Thermal>
```

へ精緻化する。

これはv0.2以降の方針を再確認するものであり、意味変更ではない。

## 7. 魔術ラテン語の法

- 命令法: 一回操作の標準表現。
- 独立した命令・規則としての接続法: 継続制約・禁止・規則の標準表現。
- 条件節・時間節・イベント節: 各動詞フレームと従属節規則に従う。接続法を一律に「条件」と同一視しない。

自然ラテン語の語順は複数許容されうるが、厳格魔術ラテン語では曖昧性を減らすため標準項順序を推奨する。
