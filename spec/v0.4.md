# 魔術言語仕様 v0.4

v0.3を基礎に、参照・同一性・所有権・寿命を定義する。

## 1. RefとEntityID

`Ref<T>` は対象そのものではなく、カーネル管理Entityへのハンドル。

```text
Entity {
    id
    type
    state
    revision
}
```

`EntityID` は再利用しない。終了済みEntityへのRefは `StaleReference`。

## 2. Identity / State

状態変化と同一性変化を分離する。

`Entity = (ID,T,S)`

移動・加熱等では通常IDを維持する。

## 3. Region

`Region` は空間集合を表す値。

`Ref<Region>` は持続的同一性・座標系等を持つ永続領域Entity。

## 4. IdentityPolicy

型ごとに連続性条件 `IdentityPolicy<T>` を持つ。

同じ構成物質でも履歴連続性等を満たさなければ同一Entityとは限らない。

## 5. RECONFIGUREと同一性

```text
reconfigure target {
    state = repaired_state;
    identity = preserve;
}
```

`preserve` は同一性保存の証明義務を生成する。

`replace` なら旧Entityを終了し、新EntityIDを発行する。

新EntityIDの発行はMKIのCREATE命令ではなく、物理変化に伴うカーネルイベント。

## 6. 分裂

一般的Objectの一対多分裂では旧同一性を終了し、新Entityを複数生成するのを原則とする。

Organism等は型固有のIdentityPolicyを持つ。

## 7. Organism / Agent

身体と人格主体を分離可能にする。

```text
body  : Ref<Organism>
agent : Ref<Agent>
```

通常は `agent embodied_by body` の関係を持つが、死亡時の扱いは上位仕様/世界設定に委ねる。

物理状態の完全な再現はAgent同一性の再現を保証しない。

## 8. Capability / Lease / Borrow

```text
Capability<Target,Domain,Operation>
Lease<Target,Domain,Mode,Lifetime>
Borrow<Target,Domain,Mode,Lifetime>
```

- Capability: その操作を行う資格
- Lease: 現在その操作領域を占有する権利
- Borrow: 一時的な限定アクセス

Write Leaseは複製禁止の線形/affine資源として扱う。

## 9. Revision

Entityの更新ごとにrevisionを増加させ、観測の陳腐化やABA問題を検知する。

## 10. Early / Late binding

発動時に毎回RESOLVEする対象指定はlate binding。

一度Refを取得し追跡する方式はearly binding。

同じ見た目の対象と同一Entityへの参照を区別する。

## 11. 保護領域

通常術者はStateを操作できても、`EntityID`, `IdentityPolicy`, `AgentIdentity` 自体の変更権限を持たない。
