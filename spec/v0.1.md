# 魔術言語仕様 v0.1

## 1. 処理系

```text
魔術ラテン語 / 高級記法
        ↓
Spell AST
        ↓
MIR
        ↓
MKI
        ↓
世界状態 Σ
```

魔法プログラム `P` は世界状態の許可された遷移として扱う。

`⟦P⟧ : Σ → Σ'`

## 2. MKI

世界へ作用する基本命令は6つに限定する。

- `RESOLVE`: 対象を一意の参照へ解決する。
- `OBSERVE`: 対象の状態を指定精度で観測する。
- `CHANNEL`: 二端点間に指定物理量の相互作用経路を確立する。
- `TRANSFER`: CHANNELを通じて保存量を移送する。
- `RECONFIGURE`: 既存物質の内部配置・状態を再構成する。
- `CONSTRAIN`: 条件を継続的に満たすためフィードバック制御を登録する。

`CREATE`, `DESTROY`, `MOVE`, `HEAL`, `BURN`, `FREEZE`, `TELEPORT`, `BARRIER` は基本命令ではなく高級ライブラリである。

## 3. Control plane

```text
ACQUIRE
RELEASE
COMMIT
ABORT
REVOKE
DELEGATE
```

これらは世界の物理状態ではなく、実行権限・Lease・術式状態を管理する。

## 4. 型とSI次元

主な基本型:

```text
Entity
Agent
Object
Region
Anchor
SpellInstance
Ref<T>
Channel<Q>
Quantity<Q,D>
```

次元は `(kg,m,s,A,K,mol)` のSI基本単位積に正規化する。

```text
Momentum = kg m s^-1
Energy   = kg m^2 s^-2
Power    = kg m^2 s^-3
Charge   = A s
```

意味型と次元は別である。

## 5. CHANNEL

チャネル開設コスト:

`E_open = α_Q σ d^2`

維持出力:

`P_maint = β_Q σ d^2`

`σ` はチャネル強度、`d` は端点間距離。

総距離 `d` を `n` 分割した場合、理想化した接続コストは `α_Q σ d^2 / n`。アンカー運用コストを加えることで最適な中継間隔が生まれる。

## 6. TRANSFER

`Channel<Q>` は `Quantity<Q>` のみ輸送できる。

保存量について原則:

`ΔQ_source = -ΔQ_destination`

## 7. RECONFIGURE

物質の無からの生成・削除ではなく、既存物質の内部構造を変更する。必要な熱・運動量等は別途 CHANNEL/TRANSFER で処理する。

## 8. CONSTRAIN

絶対命令ではなく、概念的に以下を反復する制御器である。

```text
OBSERVE
→ 誤差計算
→ TRANSFER / RECONFIGURE
→ OBSERVE
→ ...
```

制御能力を超えれば `ConstraintSaturation`。

## 9. PREPARE / COMMIT

PREPAREで対象解決、型/権限確認、Lease取得、CHANNEL確立、資源予約を行う。COMMIT後の物理変更は原則ロールバック不能。

## 10. 魔術ラテン語

格・前置詞・動詞項構造を意味解析に使用する。

- 主格: 主体
- 対格: 直接対象
- 与格: 受領者/帰着先
- 属格: 型/属性/所属
- 奪格: 起点/手段/条件

命令法は一回操作、接続法は継続制約に対応させる。

例:

`Calorem ab aqua ad aerem transfer.`

「熱を水から空気へ移せ。」

`Globus intra circulum maneat.`

「球は円内に留まるものとする。」
